# Sanchayan Banerjee Research Website

Static academic website for GitHub Pages or Netlify.

## Contents
- `index.html` — homepage
- `styles.css` — styling
- `app.js` — data, interactions, card popups, filters, cursor animation
- `assets/` — approved artwork, portrait, and CV PDF

## Deploy on GitHub Pages
1. Create a public repository named `rabiastrocosmo.github.io` on GitHub.
2. Upload all extracted files from this folder to the root of that repository.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** branch and **/(root)** folder, then save.
7. Your site should appear at `https://rabiastrocosmo.github.io/` after deployment finishes.

## Deploy on Netlify
- Drag the extracted folder into the Netlify site dashboard or connect the GitHub repository.

## Update content
- Edit the `papers`, `research`, `projects`, and `methods` arrays in `app.js`.
- Replace the CV in `assets/Sanchayan_CV.pdf`.
